FinanceControl

Sistema em ASP.NET Core + SQL Server (pasta FinanceControl/).

  1. Instale o .NET 8 SDK
  2. Execute nextFinanceDB/aplicar-banco.bat (opcional, se usar SQL manual)
  3. Execute FinanceControl/aplicar-migration.bat
